# 최신 V9 전체 S&P500 일별 재생: 입력 단계에서 차단

후속 업데이트: `docs/sp500-v9-source-recovery-2026-11-01.md`에서 잔여55종목의
13,052행 모두에 과거 공시 원문을 연결했다. 아래 수치는 최초 감사 당시 상태다.
클래스 권리와 가격 기준 미확정으로 전체 예측/계좌 비교 미완료 상태는 유지된다.

## 현재 상태

**요청한 전체 일별 V9 예측과 계좌 수익률 비교는 아직 완료하지 못했다.**
기존 20일 교집합 비교를 재실행하거나 대체 성과를 만들지 않았다.
이번에는 실제 비교 대상 전체를 펼쳐 입력 누락을 날짜별로 확인했다.

최신 완료된 재무 입력은 `tmp/quant-full-financial-study-20261101-v3/`다.
189개 과거 매출을 복구한 V9 전체 계산 연구이며, 미검증 보정 후보를 포함하지 않는다.
V9는 `StockExpectedReturnV9Service.provenanceAdjustedSnapshot`에서 양수 시가총액이 없으면
예측을 생성하지 않는다. 기존 주식수나 현재 시가총액을 과거에 복사하는 것은 허용하지 않는다.

## 고정한 비교 범위

- 기존 장기 판단일: 2025-01-02~2026-08-18.
- 기존 추가 판단일: 2026-09-17~2026-09-25.
- 총 414거래일. 당시 구성종목 패널은 208,246행·541개 고유 티커.
- 기존 기업행사 제외 및 기존 확률 모델의 입력 가능 범위에서 실제 순위 비교 대상은
  **203,461개 종목-일·524개 고유 티커**.
- 구성종목 중 원래 확률이 없는 행과 기업행사 제외 행은 삭제하지 않고 상태를 표시했다.
- 다음 거래일 시가, 익절15%·손절5%·진입일 포함20거래일, 기존 지수50일선·변동성 필터,
  초기10만 달러·최대10종목·하루2매수·직전NAV10%·편도10/20bp 그대로 유지할 예정.

이 문서의 수치는 예측 또는 수익률이 아니라 **입력 충족률 감사**다.

## 실제로 확인한 장애

읽기 전용 일관 스냅샷에서 instant 주식수 원천28,575행, 표준 재무65,251행을 확인했다.
원천 주식수는 원본 accession·공시일·측정일·값·단위가 일치하는 실제 발행주식수만 사용했다.
가중평균 희석 EPS 분모, 미래/당일 공시, 후일 주식수 소급은 금지했다.
검증된 기존 티커 변경 alias만 연결했다.

| 항목 | 결과 |
|---|---:|
| 비교 대상 종목-일 | 203,461 |
| DB에 과거 주식수 후보가 없는 종목-일 | 14,077 |
| 적어도 하루 누락된 종목 수 | 55 |
| DB 주식수 후보가 전 종목에 있는 날짜 | 0 / 414 |
| 과거 연간 재무 메타데이터가 없는 행 | 3,408 |
| 과거 독립 분기 재무 메타데이터가 없는 행 | 3,243 |

재무 결측은 기존 신호의 중립 처리와 데이터 품질 문제이며, 무조건 모델 생성 불가라는 뜻은 아니다.
주식수 후보 존재도 충분조건은 아니다. 복수 클래스의 경제적 전체 수량, 발행사·티커 동일성,
분할/분사 전후 주가·EPS·주식수 기준은 추가 확인해야 한다.
따라서 14,077행을 제외한 나머지가 모두 즉시 모델 투입 가능하다는 주장은 하지 않는다.

## 로컬 원문을 재사용한 보완

이전 검토된 ABNB·APP·DASH·DDOG·PLTR·GOOG·GOOGL·META 원문을 읽었다.
원문 해시, 클래스 합산, ABNB 내부 보유 H클래스 제외, 공시일/측정일을 확인했다.
중복된 APP 관측은 중복 계상하지 않았다.

- 원문 주식수 관측15개를 재사용하여 **1,025개 종목-일의 후보 근거를 추가 확인**.
- 남은 구조적 누락은 **13,052개 종목-일**. 여전히55종목에서 적어도 일부 날짜가 빠진다.
- 여전히414일 모두 전체 후보가 충족되지 않는다.
- 대부분2026년 원문이므로2025년 판단일을 채우지 않았다.
- 모델·운영DB에는 반영하지 않았다. 주가/기업행사 기준까지 확인하기 전이므로
  `admittedToModel=false`로 보존했다.

주요 미충족 종목에는 BF-B·EL·ERIE·EXPE·HRL·LEN·MKC·NWS·NWSA·RL·STZ·TSN·UHS 및
2025년의 GOOG·GOOGL·META·ABNB·PLTR 등이 포함된다.
55종목이 모든 날에 빠진다는 뜻이 아니다. 정확한 기간은 잔여 목록에 있다.
ECHO·FDXF·HONA·P처럼 기업행사/새 티커의 발행사 연결을 함께 확인해야 하는 경우도 있다.

## 구현과 검증

- `scripts/sp500_v9_full_preflight.py`: 읽기 전용 DB 스냅샷과 전체 일별 입력 충족표 생성.
  당시 발표 여부와 기존 alias를 확인하고, 날짜/종목 키가 정확히 일치하지 않는
  축소 예측을 전체 비교로 허용하지 않는 fail-closed 검사를 추가했다.
- `scripts/test_sp500_v9_full_preflight.py`: 실제 instant 값·원본 일치·미래/당일 제외·전체 키 검사.
- `scripts/sp500_v9_full_local_shares.py`: 기존 검증 원문을 해시/클래스 산술 대조 후
  현재 일별 범위에 보수적으로 연결. 계산 결과는 입력 후보일 뿐 예측이 아니다.
- 기존 확률 예측과 실제 원장 protocol/decision 입력 해시는 유지.
- 새 V9 예측 생성0건, 새 계좌 비교0건, 운영 DB/전략/원장/사이트 변경 없음.

## 다음 실행에 필요한 정확한 자료

`output/sp500-v9-full-preflight-20261101/remaining_share_targets.csv`의 종목과 첫 누락일을
기준으로, 그날 이전 실제 원공시의 발행주식수·클래스 권리·주가 기준을 확보해야 한다.
현재 회사 소개의 최신 주식수, 가중평균 EPS 주식수, 금일 시가총액 역산으로 채울 수 없다.
기존 원문 cache와 과거 공시부터 우선하고, 공급자 접근 제한을 우회하지 않는다.

그 후 같은 S&P500 구성종목으로 재무/가격/주식수 특징과 만기된 훈련 정답을 재구성하고,
현재 V2~V9 실제 계산 경로를 날짜순으로 재생해야 한다. 보정은 과거 OOF 예측만 사용한다.
전체 대상에 일별 V9가 생성된 것이 확인된 뒤에만 기존 확률순과 현금 포함 계좌를 비교한다.

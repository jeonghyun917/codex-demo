## Why `components/ui`

The shadcn/ui default convention is `components/ui`. It matters because examples and registry-generated imports commonly use:

```tsx
import { Button } from "@/components/ui/button";
import VolumetricBeamsFullScreen from "@/components/ui/volumetric-beams";
```

If a project uses a different path, update `components.json` aliases and TypeScript path aliases consistently. Otherwise imports generated by shadcn or copied from examples will not resolve.

## Required Dependencies

For a React app, install:

```bash
npm install three @react-three/fiber
npm install -D @types/three
```

The component uses:

- React hooks: `useMemo`, `useRef`, `useEffect`
- `@react-three/fiber`: `Canvas`, `useFrame`, `useThree`
- `three`: vectors, shader material helpers, constants
- Tailwind utility classes for sizing and text overlay

No additional context provider is required.
No image assets are required.
No lucide-react icons are required by this component.

## Setup React + shadcn + Tailwind + TypeScript

Recommended structure for this Spring Boot project is a separate frontend app, for example:

```bash
npm create vite@latest frontend -- --template react-ts
cd frontend
npm install
npm install three @react-three/fiber
npm install -D @types/three @types/node
npm install tailwindcss @tailwindcss/vite
npx shadcn@latest init
```

Then move/copy:

```text
C:\dev\codex-demo\components\ui\volumetric-beams.tsx
```

to:

```text
C:\dev\codex-demo\frontend\src\components\ui\volumetric-beams.tsx
```

and move/copy:

```text
C:\dev\codex-demo\components\ui\volumetric-beams-demo.tsx
```

to a route or page in the React app.

For Vite, shadcn's official setup expects Tailwind to be imported from `src/index.css`, TypeScript path alias `@/*` to resolve to `./src/*`, and Vite alias configuration to match.

Reference: https://ui.shadcn.com/docs/installation/vite

## Example Usage

```tsx
import VolumetricBeamsFullScreen from "@/components/ui/volumetric-beams";

export default function Hero() {
  return (
    <VolumetricBeamsFullScreen
      className="fixed inset-0 bg-black"
      title="King Yurina"
      subtitle="Quant AI"
      speed={2.95}
      beamCount={5}
      stripeFreq={800}
    />
  );
}
```

## Responsive Behavior

Default behavior:

- `className="fixed inset-0 bg-black"` makes it full-screen.
- `Canvas` uses `w-full h-full`.
- `dpr={[1, 2]}` limits pixel ratio for performance.

For embedding inside a section instead of fixed full-screen:

```tsx
<section className="relative h-[720px] overflow-hidden">
  <VolumetricBeamsFullScreen className="absolute inset-0 bg-black" />
</section>
```

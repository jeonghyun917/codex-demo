# 무료 분기 재무 보완과 고변동성 20D 검증 — 2026-11-01

## 결론

**분기 손익·연속 공시의 정보량은 크게 보완했다. 그러나 고정한 예측 보정·후보 선택 절차에서 안정적인 20D 오차 감소는 입증되지 않았다.** 연구 입력에 반영했으며 운영 V9·DB·자동 수집 설정은 변경하지 않았다.

동일한 609거래일·17,904건에서 과거 분기만 보고 후보를 선택한 절차의 MAE는 수익률 `5.749703 → 5.755483%p`, 초과수익률 `4.405489 → 4.405896%p`로 소폭 악화했다. 고변동성 구간에서는 수익률 MAE가 `8.060251 → 8.031313%p`로 감소했지만, 초과수익률 MAE는 `5.771605 → 5.774827%p`로 증가했다. 따라서 개선된 지표 하나만 골라 운영에 넣지 않는다.

기존 시험 60건은 적합·후보 선택·재평가에 사용하지 않았다. 이번 비교 역시 이미 사용한 훈련 자료의 내부 개발 검증이며 새 미사용 시험이나 실제 전방 성과가 아니다.

## 1. 무료 원본에서 무엇을 확보했는가

이미 확보한 공식 SEC companyfacts 원본 30종목과 Disney의 과거 발행사 원본을 재검사해 추출했다. 31개 원본 파일의 SHA256·CIK를 검증했다. 이번 단계에서 새 다운로드를 한 것처럼 세지 않았고 유료 자료·계정은 쓰지 않았다. SEC는 공개 회사별 XBRL 자료를 API로 제공하며, 단위와 기간·공시 문맥을 구분해야 한다. [SEC 공식 API 안내](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)

- 기간·공시별 재무 행 **1,973개**: 연간 509개, 분기 1,464개.
- 고유 `(종목, CIK, accession)` 공시 **854개**에 해당한다. 비교 기간이 같은 공시에 반복되므로 재무 행 수와 독립 공시 수는 다르다.
- **Q4 236개**: 직접 공시된 70~110일 관측치가 동일 accession의 실제 연간 종료일과 일치하는 경우만 Q4로 분류했다. 원본의 FP=FY와 분류 근거는 따로 보존했다. 연간 EPS에서 Q1~Q3 EPS를 빼서 만든 값은 없다.
- 선택값·대체 후보의 실제 원본 관측 **7,902개**를 보존했다. 다른 기간·공시를 섞어 한 재무 행을 채우지 않았다.
- 같은 개념·기간의 값 충돌 **0건**. 원본이 없거나 범위가 불명확한 값은 null로 남겼다.

전에는 실제 선택된 499개 표준 행만 있었고 과거 손익 항목이 많이 비어 있었다. 현재 팩은 더 넓은 연속 공시와 과거 비교 기간을 포함한다. **예측 표본이나 독립 정답 수가 증가한 것은 아니다.**

같은 OOF 25,473행에서, 동일한 신선도·발표 시점·단위 조건을 적용한 사용 가능 행:

동일한 회계 관측이 여러 예측일에 반복되므로 위 행 수를 독립적인 재무 관측 수로 해석하지 않는다. 기본/희석 EPS의 혼합, 비교 기간의 매출·이익 개념 변경, 발행사 변경도 차단했다. 이전 실험에서 기록한 두 EPS YoY 쌍 사이의 개념 일치 보호는 새 연구 helper에서 보완했으며 옛 봉인 코드는 바꾸지 않았다.

### 남겨 둔 실제 누락

1,973개 재무 행 중 EPS 131개, 매출 **203개**, 순이익 13개, 영업이익 728개가 비어 있다. 단순히 무료 자료가 없다는 뜻은 아니며 현재 확보한 표준 개념으로 범위를 증명할 수 없는 경우도 포함한다.

구체적 매출 누락을 원본의 개념 설명과 같은 accession·기간으로 대조했다. DOW 3개는 명시적 세금 포함 고객계약 매출로 복구했고, 세금 제외 매출과 동일한 개념으로 취급하지 않았다. 이 변경은 후보 결과를 보기 전에 완료했다. 나머지에는 다음과 같은 대체 금지 사례가 있다.

- AMGN/JNJ/KO/MRK의 goods 매출: 상품 매출만으로 연결 전체 매출이라고 증명할 수 없다.
- CRM의 services·technology-services 매출: 서비스·훈련·설치 등의 범위를 연결 전체 매출로 임의 확대하지 않았다.
- AXP의 noninterest income: 이자 부문이 빠져 있어 전체 매출을 대신할 수 없다.
- 인수 pro forma·보고 부문 매출: 실제 연결 매출과 바꾸지 않았다.

이 203개 행은 개별 원문 손익계산서·주석으로 연결 범위를 추가 검증해야 한다. 자료 가용 비율을 올리기 위해 부적절한 대체값이나 0을 넣지 않았다.

## 2. 무엇을 시간순으로 검증했는가

원본 V9의 실제 일별 시간순 OOF 예측과 정답을 고정했다. 전체 OOF 25,473행·870날짜 중 주 평가는 2018Q2~2020Q3의 609날짜·17,904행이다. 2020Q3는 8월 28일까지이고, 사용할 수 있는 최종 정답 종료일은 9월 29일이다. 60건 시험 창의 정답·시험 예측 배열은 읽지 않았다.

새 분기 자료를 사용한 **보정 후보**를 검증한 것이며, 자료를 보완한 V9 전체를 처음부터 다시 만드는 실험은 아니다. 비교 기간과 정답을 바꾸지 않고 추가 지표·보정 효과를 분리하기 위한 선택이다.

후보 5개와 기준은 첫 결과 전에 고정했다.

1. **V9** — 보정 없음.
2. **확장 분기 재무** — EPS 성장·가속, 실제 매출·순이익률·영업이익률·매출 가속, 누락·개념 표식과 기존 V9·시장 맥락. 분기 시작 전 만기가 끝난 자료로 Ridge 100을 적합한다. `.25 × clip(잔차예측, −2,+2)`로 머리별 보정은 최대 ±0.5%p다.
3. **고변동성 시장만** — 날짜별 한 관측으로 시장 성분을 학습한다. 정답은 실제 벤치마크 수익률에서 V9의 암묵적 시장 예측(`수익률−초과수익률`)을 뺀 잔차다. 과거 시장 5/20/60일 수익률·변동성·낙폭과 암묵적 시장 예측만 사용한다. 분기 고정 Ridge 100, 관측 변동성 25% 이상에서만 최대 ±1%p를 수익률 머리에 더한다. 초과수익률은 바꾸지 않는 분해용 통제 후보다.
4. **분기 재무+고변동성 시장** — 위 두 보정을 그대로 합산한다. 수익률 최대 ±1.5%p, 초과수익률 최대 ±0.5%p다.
5. **최근 시장국면 보정** — 각 예측일에 이미 만기가 끝난 같은 관측 변동성 국면의 최근 63개 날짜를 사용한다. 같은 국면이 20날짜 미만이면 전체 최근 63날짜로 돌아가고, 그것도 20날짜 미만이면 보정하지 않는다. 날짜별 평균 잔차의 중앙값을 최대 ±0.5%p로 제한한다. 이는 분기 고정이 아니라 **일별로 과거 만기 자료만 갱신하는 알고리즘**이다.

변동성 국면은 관측 연율 변동성 15% 미만, 15~25%, 25% 이상으로 고정했다. 실제로 미래 시장이 올랐는지·내렸는지는 지표로 넣지 않았다.

각 outer 분기의 선택은 이전 3분기만 사용한다. 두 머리의 3분기 평균 MAE가 각각 V9보다 작고, 두 평균 RMSE가 악화하지 않아야 한다. 추가로 **각 분기 두 MAE의 V9 대비 비율을 평균한 값**이 1 미만인 분기가 3개 중 2개 이상이어야 한다. 이것은 각 머리 각각이 2분기 이상 개선돼야 한다는 별도 규칙이 아니다. 통과 후보 중 평균 비율/고정 순서로 선택하고 없으면 V9다. 선택 규칙을 결과 후 더 엄격하게 또는 느슨하게 바꾸지 않았다.

분기 고정 모형은 학습 signal·exit가 모두 분기 시작보다 이전이어야 한다. 일별 보정은 학습 signal·exit 모두 해당 예측일보다 이전이어야 한다. inner 선택에 쓴 정답도 outer 시작 전에 만기가 지나야 한다. 같은 날 만기는 이용하지 않았다.

주 판정 대상인 선택 절차의 V9 대비 MAE 차이는 다음과 같다. 음수가 개선이며, 21개 전체 결정 날짜 블록을 1,000회 재표집했다.

- 수익률: **+0.005780%p**, 95% 구간 **[−0.017468,+0.033947]**.
- 초과수익률: **+0.000406%p**, 95% 구간 **[−0.000526,+0.001570]**.

선택 절차는 9개 분기에서 V9, 2020Q1에서 확장 분기 재무 후보를 선택했다. 이 분기의 수익률 MAE는 V9보다 0.056779%p 높았다. 과거 조건을 통과한 후보가 다음 분기에 개선된다는 보장은 없었다. 전체 성적을 본 뒤 결합 후보나 빠른 보정 후보를 대신 고르지 않았다.

## 4. 고변동성 구간은 나아졌는가

주 평가 중 예측 당시 시장 연율 변동성이 25% 이상인 **109날짜·3,250행**만 같은 조건으로 비교했다.

| 방식 | 수익률 MAE(%p) | 초과수익률 MAE(%p) |
|---|---:|---:|
| V9 | 8.060251 | 5.771605 |
| 확장 분기 재무 | 8.114284 | 5.791674 |
| 고변동성 시장만 | 8.018286 | 5.771605 |
| 분기 재무+시장 | 8.081228 | 5.791674 |
| 최근 시장국면 보정 | 8.005875 | 5.776047 |
| 과거만 보고 선택 | 8.031313 | 5.774827 |

시장 성분 보정은 고변동성 수익률 MAE를 약 0.0420%p 줄였다. 최근 국면 보정은 약 0.0544%p 줄였지만 초과수익률은 나빠졌다. 선택 절차도 수익률은 −0.028937%p, 초과수익률은 +0.003222%p로 두 목표를 함께 개선하지 않았다.

고변동성 조건부 선택 절차의 95% 구간은 수익률 **[−0.119799,+0.050571]**, 초과수익률 **[0,+0.008894]**다. 109개 날짜만 압축해 재표집하지 않고 **전체 609개 날짜의 21날짜 블록을 재표집한 뒤**, 각 표집에서 고변동성 날짜로 조건부 평균을 계산했다. 고변동성 날짜가 없는 표집은 제외하고 유효 1,000회를 사용했다.

따라서 “고변동성 오차 해결”이라고 부르지 않는다. 특정 머리의 숫자만 낮거나 전체 평균이 아주 조금 낮은 것과 안정적인 실제 예측력은 다르다.

## 5. 남는 제한과 적용 결정

- 현재 SEC 파일로 과거 accession·공시일 관측을 복원한 것이며 과거 당시 API 응답 스냅샷은 아니다. 원본 공시일 조건만으로 이 한계가 사라지지는 않는다.
- 정해진 과거 모집단과 반복 노출 훈련 자료를 재사용했다. 생존 편향·모집단 선택·겹치는 20일 정답이 남아 있고, 행 수가 독립 표본 수는 아니다. 새로운 미사용 기간이나 실제 전방 성과라고 주장하지 않는다.
- 분기 YoY는 동일 CIK·개념·실제 기간으로 제한했다. 금융사의 순이자 차감 매출, 세금 포함 매출, parent 귀속 순이익과 비지배지분 포함 손익은 이름만 보고 동일하게 섞지 않았다. 개념 전환은 지표 누락으로 처리했다.
- 일별 적응형 모형은 해당 시점까지 만기가 지난 검증 구간 내 옛 정답을 정상적으로 갱신에 사용할 수 있다. 미래 정답 변경 검사는 이 성질을 고려해 현재 예측의 불변성을 검사했다. 나중에 정답이 공개된 뒤의 예측까지 불변이어야 한다고 잘못 요구하지 않았다.
- 기존 60건은 사용하지 않았으며 운영 가중치·DB·자동화·서버·Git 브랜치/인덱스/HEAD/푸시는 바꾸지 않았다. 단순히 자료를 확보했다는 이유로 운영 모델을 교체하지 않았다.

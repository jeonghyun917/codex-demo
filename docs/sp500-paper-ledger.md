# S&P500 두 조건 결합 모의운용 원장

## 상태

2026-10-31 구현 및 초기화 완료. 실제 원장은 `data/sp500-paper-ledger`에 있다.
실거래 주문 및 예약 실행은 하지 않는다. 웹 조회 화면은 `/paper-trading`에 추가됐다.
원본 원장은 파일로 보존하며, 웹 페이지는 아래 게시 명령으로 저장한 DB 조회 스냅샷만 읽는다.
기존 V9 종가 예측 관측 프로그램과 별도이며 그 프로그램의 자동 실행에 연결하지 않았다.

초기 실행 결과:
- 원장 생성: 2026-10-31T11:17:20.747941Z
- 실제 예측 기록 0일, 모의 거래 0건
- capture: STALE_DATA로 차단. 기본 승인 데이터의 마지막 날짜는 2026-10-23이며 현재 최신 완료 장은 2026-10-30이다.
- evaluate: NO_CAPTURED_DECISIONS. 성과를 만들어 내지 않았다.
- 관련 회귀 테스트 45개 통과(신규 원장 테스트 9개 포함).

## 고정 규칙

- S&P500 유효 특징 종목의 상승 목표 선도달 확률 상위 20%를 먼저 선택.
- 지수 종가가 50일 평균 위이고, 개별 20일 변동성이 해당 일 종목군 75백분위 이하일 때만 후보 유지. 상위 20% 밖으로 보충하지 않는다.
- 기존 기업행사 제외 목록 유지. 기존 가격 전용 보정 로지스틱 모델, 월별 expanding 학습, 주간 학습 표본, 126세션 보정 구간 및 결과 만기 분리를 재사용.
- 다음 거래일 시가 모의 진입. 익절 +15%, 손절 -5%, 진입일 포함 최대 20거래일. 손절 갭은 시가, 익절 갭은 보수적으로 목표가, 일봉에서 양쪽을 모두 터치하면 손절 우선.
- 초기 현금 100,000달러, 최대 10종목, 일 신규 최대 2종목, 종목당 전일 자산의 최대 10%, 정수 주식, 무차입. 편도 비용 0.1% 및 0.2% 별도 계좌.
- 배당, 현금 이자, 세금, 환율 및 실제 주문체결 오차는 포함하지 않는다.

## 사용

작업 폴더 `C:\dev\codex-demo`에서 실행한다. 실제 원장은 이미 생성돼 있으므로 init을 다시 실행하면 덮어쓰지 않고 거절한다.

```powershell
python scripts/sp500_paper_ledger.py status
python scripts/sp500_paper_ledger.py capture --dataset <최신-검증-데이터셋-경로>
python scripts/sp500_paper_ledger.py evaluate --dataset <실제-결과가-추가된-검증-데이터셋-경로>
```

capture는 해당 장 마감 후부터 바로 다음 거래일 개장 직전 사이에 실행해야 한다. 주말은 금요일 마감 후 월요일 개장 전 구간으로 처리한다. 시간대는 달력의 UTC를 사용하므로 미국 서머타임과 조기 폐장을 반영한다.

명령행에 과거 저장 시각을 지정하는 기능은 없다. 실행 시점의 시스템 시각으로 기록하며, 계산 전·후와 파일 저장 후까지 시간을 검사한다. 다음 장 개장 시각과 같거나 늦으면 기록을 주문 근거로 인정하지 않는다. 누락된 날을 나중에 과거 예측으로 보충하지 않는다.

## 입력 데이터 승인 조건

`build_sp500_daily_dataset.py` 형식의 일별 패널·가격 이력·별칭·달력·기업행사 격리 및 manifest가 필요하다. 독립 검증 결과 `verification.json`이 PASS여야 하며 manifest의 입력 해시가 일치해야 한다. 최종 날짜가 최신 완료 세션과 정확히 같아야 한다. 적어도 기존 학습·보정 구간과 63세션 연속 특징 이력을 갖춰야 한다.

원본 스냅샷이나 현재 사이트 V9 값만으로는 이 전략의 예측을 대신 생성할 수 없다. 새 가격은 기업행사·종목 식별·구성 이력 확인을 거쳐 데이터셋으로 승인한 뒤 공급해야 한다. 현재 준비된 10/28 원본 역시 10/30 예측에는 부족하다.

입력 파일 해시는 계산 전후 비교하고 기록마다 저장한다. 재현을 위해 승인 데이터셋 버전도 보존해야 한다. 공식 시점별 전체 구성종목 인증 및 가격 조정 문제 등 기존 연구 데이터 한계가 해소됐다는 의미는 아니다.

## 저장 구조

- `protocol.json`: 초기화 실제 시각, 전략 규칙, 제외 목록, 달력, 코드·수치 라이브러리 버전 및 해시.
- `decisions/YYYY-MM-DD.json`: 모든 예측 대상 종목의 확률·특징, 필터 통과 순서, 데이터 해시, 학습 시점 감사, 판단일, 다음 시가 진입일, 기록 시각.
- `receipts/YYYY-MM-DD.json`: 예측 파일 저장 완료를 확인한 시각과 예측 해시. 없거나 개장 후라면 불완전 기록으로 차단한다.
- `evaluations/시각-고유번호.json`: 실제 일봉을 사용한 모의 매수·매도 이벤트, 종료 거래, 현금·평가금액·전체 자산 곡선, 최대낙폭, 예측 확률과 실제 목표 선도달 여부.

파일은 신규 생성만 허용한다. 이미 존재하는 판단일은 재작성하지 않는다. 프로토콜·예측·평가는 무결성 해시를 확인한다. 로컬 관리자에 의한 시계·파일 조작까지 막는 외부 공증 원장은 아니다.

## 결과 해석

수익률은 예측된 수익이 아니라 실제 이후 OHLC를 적용한 모의 체결 결과다. 실제 증권사 체결 내역이 아니다. 순위는 당시에 저장한 순서만 사용하며, 그 뒤 결과를 보고 종목을 바꾸지 않는다.

진입에 필요한 가격이나 보유 가격이 없거나 격리되면 계좌 계산을 중단해 사유를 반환한다. 포지션이 열려 있으면 전체 완료 수익률은 null이며 `prefix_return_pct`는 그 시점의 평가손익이다. 미기록 세션에는 신규 주문을 만들지 않되 기존 포지션은 계속 평가한다. `missedCaptureSessions`에 해당 날짜를 표시한다.

종료 거래의 `predictedProbability`, `actualTargetFirst`, `brierSquaredError`를 통해 예측과 결과를 비교한다. 이는 선택된 종료 거래에 한정된 값으로 전체 종목의 확률 보정 성능으로 해석하면 안 된다. 평가를 반복하면 새 결과 파일에 사용한 가격 해시를 남기며 이전 결과는 유지한다. 공급자 가격 수정 때문에 같은 거래의 재평가 결과가 달라질 수 있다.

달력은 2026-12-31까지의 기존 공식 일정 전사 자료를 사용한다. 임시 휴장 또는 달력 범위 만료, 코드·제외 목록·수치 라이브러리 변경은 묵시적으로 적용하지 않고 별도 버전 검토가 필요하다.

## 사이트 조회

상단 `Quant → 모의운용 → Stocks`에서 모의운용을 선택하거나 `http://127.0.0.1:8080/paper-trading`을 연다.
예측 판단일 선택, 종목 검색, 비용 0.10%/0.20% 계좌 비교와 종료 거래별 예측 확률·실제 손익을 제공한다.
예측 및 평가가 없는 상태에서는 수익률을 0으로 가정하지 않고 `-`로 표시한다.

capture 또는 evaluate가 성공한 뒤 아래 명령으로 웹 조회 스냅샷을 갱신한다. 자동 동기화는 아직 설정하지 않았다.

```powershell
python scripts/publish_sp500_paper_view.py --publish
```

이 명령은 원장의 해시·저장 완료 기록을 검증하고, 기존 `stock_dashboard_view_snapshot` 테이블의
`SP500 / SP500_PAPER_WEB_V1` 한 행 및 `main_menu`의 `paper-trading` 한 항목만 갱신한다.
원본 예측·평가, 기존 Quant 대시보드 버전, 가격 데이터와 매매 규칙은 변경하지 않는다.
페이지의 `조회 데이터 동기화` 시각은 마지막 게시 시각이며 원장의 실시간 갱신 시각이 아니다.

## 과거 확률 구간별 청산 통계

`과거 검증 근거 → 확률 구간별 실제 청산 결과`에서 기존 구간과 짧은 과거 구간,
편도 비용 0.10%와 0.20%를 각각 선택한다. 기간·비용 시나리오를 합쳐 중복 집계하지 않는다.
원본은 `output/sp500-actions-20261028-retry/revalidation_fills.csv`의 `TREND50_VOL75` 종료 거래다.
민감도 잡음 시나리오는 제외하며, 판단일과 티커로 해당 구간의 저장된 예측 확률을 연결한다.

- 확률 구간은 `[0%, 10%)`부터 `[90%, 100%]`까지 고정한다. 전략 선별 조건이 아니다.
- 익절률은 TP 비율, 손절률은 SL 및 SL_GAP 비율, 기간 청산률은 TIME 비율이다.
- 거래 수는 청산 거래 기준이다. 같은 종목의 재진입은 별도 거래이며 독립 표본을 보장하지 않는다.
- 평균 순수익률은 `100 * pnl / budget`의 단순평균이다. budget은 매수 비용을 포함하고 pnl은 매도 비용까지 차감한 손익이다. 현금 포함 계좌 수익률과 혼용하지 않는다.
- 빈 구간은 null(`-`), 30건 미만은 소표본으로 표시한다. 30건은 표시 기준일 뿐 통계적 유의성 기준이 아니다.
- 이미 확인한 과거 구간의 선택된 거래 통계다. 전체 예측의 보정 성능이나 현재 종목의 기대수익률로 해석하지 않는다.

산출물은 `output/sp500-probability-bins-20261101/report.json`, 연결 거래는 `joined_trades.csv`,
독립 대조 결과는 `verification.json`이다. 게시 시 보고서·연결 거래·원본의 해시를 확인한다.
자료가 없거나 변경되면 통계를 0으로 대체하지 않고 조회 불가로 표시한다.

```powershell
# 새 출력 폴더에서만 생성한다. 기본 산출물은 이미 존재하므로 덮어쓰지 않는다.
python scripts/sp500_probability_bins.py --out output/sp500-probability-bins-check
python scripts/verify_sp500_probability_bins.py --out output/sp500-probability-bins-check
```

사이트 게시자는 검증 완료된 `sp500-probability-bins-20261101` 버전을 사용한다.
새 산출물을 사이트에 연결하려면 독립 검증 후 게시자의 버전 경로를 명시적으로 변경해야 한다.
확률 구간 분석은 원장, 예측, 진입·청산 조건을 수정하지 않는다.

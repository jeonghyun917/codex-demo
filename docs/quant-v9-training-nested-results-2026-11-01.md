# V9 오차 원인과 지표·가중치 후보 검증 — 2026-11-01

## 결론

**검증한 지표·가중치 변경에서 신뢰할 만한 20D 오차 감소는 확인되지 않았다.** 자동 후보 선택 절차는 기존 V9와 사실상 동률이다. 운영 모델과 DB는 변경하지 않았다.

다만 개선을 막는 입력 한계를 구체적으로 확인했다. 뉴스·기관·애널리스트 점수는 전부 50으로 고정돼 있고, 기존 훈련 26,401행 중 선택된 공시 네 종류 어느 곳에도 EPS가 없는 행이 20,899개다. 다음 데이터 보완은 가격 행 수보다 **과거에 실제 공개됐던 지표의 내용과 가용성**을 우선해야 한다.

## 무엇을 사용했는가

- 기존 훈련 26,401행과 실제 시간순 V9 OOF 25,473건만 사용했다. 기존 시험 60건의 정답 파일과 target/baseline 예측 배열은 사용하지 않았다.
- 지표 입력 시점은 2020-08-28까지, 허용된 기존 훈련 정답 만기는 2020-09-29까지다. 미래 보유 종가나 실현 벤치마크 수익률을 지표로 넣지 않았다.
- 원인 진단은 전체 870개 OOF 시점, 후보 평가의 공통 표본은 **2018Q2~2020Q3의 609개 시점·17,904행**이다. 2020Q3는 8월 28일까지인 부분 분기다.
- 기존 60건의 MAE나 전체 훈련의 MAE와 숫자를 직접 비교해 개선이라고 주장하면 안 된다. 기간·표본·평균 방법이 다르다.
- 이는 **훈련 내부의 회고적 모델 개발 검증**이다. 새로운 미사용 시험이나 실제 전방 성과가 아니다. 후보 실행 전 V9의 기술적·입력 진단을 본 사실도 프로토콜에 명시했다.

## 오차를 키우는 것으로 관찰된 조건

### 입력의 정보량 부족

전체 훈련 26,401행 기준:

| 항목 | 관찰 |
|---|---:|
| 섹터 UNKNOWN | 26,401행 |
| 뉴스·기관·애널리스트 점수 | 각 항목 전부 50 |
| 품질 점수 50 | 23,759행 |
| 안정성 점수 50 | 23,287행 |
| 가치 점수 50 | 23,225행 |
| 선택된 공시 중 EPS가 하나라도 존재 | 5,502행 |
| 선택된 공시 어디에도 EPS가 없음 | 20,899행 |

50은 실제 중립일 수도 있고 대체값일 수도 있으므로, 50이라는 이유만으로 누락으로 분류하지 않았다. 실제 공시 선택 감사 자료의 missing 표식과 EPS 필드를 사용했다. 누락 표식 자체도 연도별 자료 확보 차이를 반영할 수 있어 경제적 예측 신호라고 단정할 수 없다.

과거 자료의 EPS 가용성은 2017~2019년에 특히 낮다. 최신 분기 공시의 EPS가 있는 행은 2017년 232/6,728, 2018년 251/7,279, 2019년 603/7,384, 2020년 3,454/5,010이다. 모든 재무 기록이 오래된 EPS를 사용한 것은 아니다. EPS가 실제로 있는 최신 연간/분기 기록의 최대 기간 나이는 각각 423/220일이었다.

### EPS가 빠진 단계의 추가 추적

2017~2019년 최신 연간/분기 선택 중 EPS-null인 비어 있지 않은 재무 **선택 기록 37,712건**에는 보존된 `candidateFieldEvidence`의 EPS 후보가 전부 없었다. 이는 고유 훈련 행 수가 아니다. 표준화 코드는 사용 가능성·택소노미·단위·개념 필터를 통과한 뒤에만 후보를 기록하므로, 현재 근거만으로는 상위 원본에 EPS가 없었는지 사전 필터에서 제외됐는지 구분할 수 없다. 무료 공시에 EPS가 없다는 증거로 해석하면 안 된다.

2020년 EPS-null 선택 692건에는 후보가 남아 있다. 예를 들어 AMGN 2020-02-13의 연간 선택에 남은 EPS 후보는 92일짜리 Q4이고 연간 기간은 365일이므로, 기간 불일치로 제외한 것은 맞다. 반면 WBA 2017년 연간 EPS 3.82와 AAPL 2020년 분기 EPS 2.58은 실제 원문 관측값과 함께 정상적으로 보존됐다. 원인 추적 표본과 전체 기록 집계는 별도 영수증에 남겼다.

따라서 다음 수집·표준화 개선은 **후보 생성 전 단계의 원본 존재 여부와 제외 사유를 기록하고 복구하는 것**이다. EPS를 억지로 채우기 위해 연간/분기·주당 단위·공시일 검사를 완화하면 안 된다.

### 같은 날짜에 함께 발생하는 오차

전체 OOF 제곱오차의 45.36%는 같은 날짜의 평균 오차 성분이며, 2020년에는 58.67%였다. 종목별 가중치만 바꿔 해결할 수 있는 문제인지 의심해야 한다. 다만 이는 오차의 회계적 분해이지 시장 방향이 원인이라는 인과 증명은 아니다.

실현 수익률은 벤치마크와 종목 초과수익률로 나눴다. 예측 오차도 같은 방식으로 분해했으며, 두 성분의 교차항을 포함해야 제곱오차가 일치한다. MAE를 두 성분으로 단순 합산하지 않았다.

## 실제 후보 비교

33개 시점 가용 지표를 사용했다: V9 두 점예측, 기존 12개 점수와 시가총액, 과거 가격·시장 지표, 공시 누락·기간 나이. 가중치는 과거 자료로만 학습했고 상수 열은 실질적으로 신호를 만들지 않는다.

10개 분기마다 앞선 3개 분기에서만 후보를 선택했다. 학습과 선택에 쓴 모든 정답은 해당 기준일보다 먼저 만기가 지나야 한다. 처음 2017Q2에 만기 OOF가 없는 문제를 피하려고 외부 분기 평가는 2018Q2부터 고정했다.

아래 오차는 같은 17,904행에서 날짜별 종목 평균을 낸 뒤 날짜를 동일 가중한 MAE(%p)다.

주된 판정 대상은 마지막 자동 선택 절차다. 전체 분기 성적을 본 뒤 가장 좋은 후보를 새로 고르는 방식은 사용하지 않았다. 나머지 후보의 전체 성적은 원인 진단용이다. 제외 실험은 명시적으로 추가한 지표만 제외하며, V9·기존 점수에 이미 들어 있는 시장/가격 정보를 완전히 제거한 인과 실험이 아니다.

자동 선택은 V9 4분기, 단순 중앙값 4분기, 두 가중치 후보를 각각 1분기씩 선택했다. 학습 때의 개선이 다음 분기에 보장되지는 않았다. 예를 들어 2019Q3 중앙값 선택은 다음 분기의 두 MAE를 늘렸고, 2020Q3 가용성 지표 제외 후보도 두 MAE를 늘렸다.

## 개선이 검증됐는가

자동 선택의 수익률 MAE 감소는 **0.000082%p**, 초과수익률 MAE 감소는 **0.008190%p**다. 수익률 RMSE는 8.306307→8.331994%p로 소폭 악화됐다.

날짜 전체를 묶어 21시점 이동 블록으로 계산한 MAE 차이의 95% 구간은 다음과 같다. 음수는 개선이다.

- 수익률: -0.188597~+0.195236%p
- 초과수익률: -0.024941~+0.005017%p

둘 다 0을 포함한다. 이는 선택된 예측들의 조건부·근사 불확실성 평가이며 전체 모델 개발 과정의 모든 선택 불확실성을 포함하지 않는다. 일별 20D 정답과 종목들이 독립 표본이라는 주장은 하지 않는다.

## 학습한 가중치의 의미

모든 분기의 표준화 계수·절편·학습 평균/스케일·만기 기준은 결과 파일에 저장했다. 이 계수는 기존 지표 점수의 비율(%)이 아니라 **추가 점예측 모델의 계수**다. 운영 점수 가중치로 그대로 복사하면 안 된다.

잔차 Ridge100의 수익률 모델에서는 시장 변동성·60일 시장 수익률·V9 수익률 예측에 음의 계수가 10분기 모두 나타났다. 하지만 이 후보 자체의 검증 오차가 기존 V9보다 컸으므로 유효한 추천 가중치로 보지 않는다. EPS 누락 여부에도 큰 계수가 나타나는데, 이는 자료 수집 시기 차이를 학습한 것일 수 있다.

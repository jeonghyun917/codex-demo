# 무료 거시자료 반영 및 예측·백테스트 검증 결과

## 결론 — 연구 비교는 검증됨, 실전 승격·포트폴리오 성과 인증은 불가

2026-10-18 확보한 ALFRED 자료를 실제 새 연구 데이터셋에 반영했다. 기존 예측과
동일한 날짜·종목·실현가격으로 비교했을 때 V8/V9의 확률 오차와 초과수익률 MAE는
소폭 감소했다. 모든 구성종목이 갖춰진 날짜는 0개이므로 누락 종목을 제외한
포트폴리오 CAGR나 수익률을 대신 발표하지 않았다. 운영 승격 판정은 여전히
`INSUFFICIENT_DATA`다. 이는 수익성 입증이나 검증 전체 완료를 뜻하지 않는다.

분석 공개 수준: **Share with caveats — 재구성 연구 비교에 한정**.

## 실제 반영 범위

- 원자료: 무료 ALFRED 276개 파일, 유효 관측값 59,368행, 7개 시계열.
- 역사적 결정일 37개: 2023-04-28–2026-03-27. 각 결정일의 전날 as-of 자료만 사용.
  최신 비교용 자료는 역사적 예측에 넣지 않았다. 공시 시각·수신 시각을 추정하지 않았다.
- 새 연구 namespace: `SP500_MACRO_FREE_20261018`, `NASDAQ100_MACRO_FREE_20261018`.
  각 37개 특성행, 합계 74개. S&P 예측 날짜는 37개, Nasdaq은 V7 입력이 존재하는 34개다.
- 동결 기준 데이터의 V7·구성종목·가격 벤치마크·기존 시장 문맥을 복사하고 영향받는
  V8/V9만 계산했다. V2–V7 모델 전체를 재실행하지 않았다.
- 등록·복사·특성·V8/V9는 namespace별 하나의 트랜잭션으로 완료됐다. 같은 입력/코드
  해시가 등록된 경우 재개는 완료 데이터를 재사용하며 다른 해시 덮어쓰기는 거부한다.
- 실제 계산 시각은 2026-10-18로 보존했다. `LIVE`, `OFFICIAL_PIT`, 역사적 수신시각으로
  바꾸지 않았다. 기존 점수식을 재사용했으며 결과에 맞춰 계수를 조정하지 않았다.
- VIX·달러의 기존 `20d` 필드는 현행 모델과 동일한 30달력일 비교 프록시다.
  20거래일을 새로 계산했다고 주장하지 않는다.

## 동일 모집단 비교

20거래일 초과수익률 기준. Brier는 낮을수록 좋고, MAE 단위는 **퍼센트포인트**다.
각 행의 전후 비교는 동일한 이용가능 표본이며 누락은 대상 분모에 그대로 남는다.
지수 간·V8/V9 간 표본이 같다는 뜻은 아니다.

| 지수/모델 | 이용가능 / 대상 | Brier 이전 → 반영 | MAE 이전 → 반영 | 방향 일치율 이전 → 반영 |
| --- | ---: | ---: | ---: | ---: |
| S&P500 V8 | 16,899 / 18,612 | 0.249237 → 0.248735 | 5.869319 → 5.857669 | 53.5594% → 54.4707% |
| S&P500 V9 | 16,794 / 18,612 | 0.249240 → 0.248734 | 5.870472 → 5.858689 | 53.5370% → 54.4540% |
| Nasdaq100 V8 | 3,130 / 3,738 | 0.248713 → 0.247966 | 7.213853 → 7.197409 | 54.1214% → 55.5272% |
| Nasdaq100 V9 | 3,130 / 3,738 | 0.248761 → 0.248029 | 7.214331 → 7.198312 | 54.1214% → 55.5272% |

대조군 V7은 양쪽 namespace에서 모든 진단 지표가 같다. V8의 날짜 내 순위 IC도
불변이다. 날짜별 공통 이동을 적용하는 구조이므로 이를 새로운 종목선별 알파로
해석하지 않는다. V9 IC는 S&P 0.01049075 → 0.00995653으로 하락,
Nasdaq 0.03045426 → 0.03119358으로 상승했다. 예측구간 포함률은 두 지수 V8/V9
모두 소폭 하락했다. 즉 모든 지표가 개선된 것은 아니다.

겹치는 20일 라벨과 공통 거시 환경을 공유하는 종목은 독립 표본이 아니다.
유의성 검정·새로운 미사용 홀드아웃 성과 검증은 수행하지 않았다. 소폭 개선을
안정적인 투자 우위나 인과 효과로 해석할 수 없다.

## 백테스트 가용성 및 남은 차단 사유

모든 37개 결정일에서 전체 구성종목의 예측·가격·벤치마크를 충족해야 해당 날짜를
포트폴리오 평가에 포함하도록 했다. 양 지수 모든 비교 모델에서 **완전한 날짜 0개,
포트폴리오 기간 0개**다. 수익률·Sharpe·낙폭 등은 0%가 아니라 `NaN`/사용불가다.
왕복 편도 10bps 비용과 비중복 보유 평가 계약은 유지했지만 평가 가능한 기간이 없다.

S&P V8 누락 대상 1,713개, V9 1,818개; Nasdaq V8/V9 608개가 남는다. 이는
종목-결정일 키의 누락 수이지 서로 다른 누락 종목 수가 아니다. 예측 부족과 가격/기간
부족이 겹치므로 모두 가격 누락이라고 해석하지 않는다. 세부 날짜별 제외 수는 JSON에 있다.

운영 strict 평가 ID 5는 입력이 변하지 않아 재사용했다. 원 대상 33,983개,
적격 행/월 0/0, `INSUFFICIENT_DATA`; 승격 문턱을 낮추지 않았다. 과거 공식 구성종목
기준명부/변경사슬, 역사적 입력 가용시점, 상장폐지 종목 가격·회수·기업행사 정산,
배당 포함 총수익 벤치마크 등이 여전히 부족하다. 현재 지수 가격 벤치마크는 총수익률이 아니다.

## 추가 확보한 무료 1차 근거

기존 가격 조회 실패 57종목 중 CERN, MXIM, SPLK, XLNX, DRE, FRC, ABMD, SGEN의
인수·상장폐지·법정관리 관련 **8건**을 Nasdaq/SEC/발행사/FDIC 원문으로 확보했다.
유효 원문 8개와 거부한 점검 안내문 1개를 해시·URL·수집시각과 함께 보존했다.
무료·무계정 공개 경로만 사용했으며 접근제한을 우회하지 않았다.

이 근거는 가격 이력 8종목을 복구한 것이 아니다. 신규 OHLCV는 0행이며 57종목의
가격 공백은 남아 있다. ABMD의 조건부 CVR 최대 $35를 확정 현금에 더하거나,
FRC의 예금 인수를 주주 회수액으로 해석하지 않았다. 후일 문서의 효력일을 예측 입력의
가용일로 소급하지 않았다. 기존 ADD/REMOVE/SPLIT/DIVIDEND 적재기에 합병을
다른 행사로 위장해 넣지 않았다. 행사별 출처·금액·제한은 별도 보고서에 정리했다.

참고: `docs/quant-extra-evidence-2026-10-18.md`.

## 후속 우선순위

1. 남은 구성종목별 예측/가격/벤치마크 제외 사유에서 가장 적은 보완으로 완전한 날짜를
   만들 수 있는 구간부터 다룬다. 누락을 삭제해 완전성을 만들지 않는다.
2. 8개 행사 근거를 이용한 별도 terminal-event staging을 만든 뒤 현금/주식/CVR·단주·지급일
   회귀 검증을 갖춰야 실제 수익 정산에 반영할 수 있다.
3. 공식 과거 기준명부와 기업행사 전후 동일 기준 가격, 미사용 홀드아웃을 확보해야
   실전 승격을 다시 판단할 수 있다. 무료 공개자료만으로 모두 해결됐다고 주장하지 않는다.

이 작업은 main의 로컬 변경만 저장했다. 커밋·푸시·배포를 하지 않았고 웹 서버도
재기동하지 않았다. 브라우저 GET 경로와 운영 모델 판정은 바꾸지 않았다.

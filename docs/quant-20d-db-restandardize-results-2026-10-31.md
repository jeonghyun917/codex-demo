# 실제 DB 재표준화와20D 재검증 결과

## 결론

기존 표준 재무 DB의 실제 재표준화를 안전장치와 복구 검증 후 커밋했다.
원천705,321행은 수정하지 않았고 표준65,115행의 ID/고유키/행 수를 보존했다.
수정된 입력으로20판단일×101종목을 다시 계산하고, 실제10개 지표 가중치도 시간순으로 학습했다.
**이번 자료에서 예측 오차가 개선됐다고 입증하지 못했다. 새 가중치를 운영에 적용하지 않았다.**
자료 정정의 필요성과 예측력 향상은 별개의 결론이다. 오차가 나빠졌다고 오류 자료를 다시 사용하지 않는다.

## 2. 정정 입력으로 같은20D 다시 검증

대상은 이전 실험의 동일한20개 불연속 판단일과 당시 재구성된101종목, 총2,020개 관측이다.
같은 종목·같은21개 종가·같은 벤치마크·같은 기존 모델 수식을 사용했다.
V2–V9 총16,160예측을 새로 계산했지만 서로 다른16,160독립 표본이라고 세지 않는다.
예측 타깃은 다음 거래일 종가 진입→20거래일 뒤 종가이며, 배당포함 수익률이나 실제 시가 체결 성과가 아니다.

## 4. 실제 전방 검증 준비 상태

실제 현재 UTC 시각으로 SP500/NASDAQ100/DOW30 각각 index-bound V2 프로토콜을 초기화했다:
`data/quant-forward-validation-20261031-v2/<index>/protocol.json`.
벤치마크는 해당 index의 저장 가격수익률 프록시와 명시적으로 결합하고 다른 지수 표본은 제외한다.
잘못된 index 혼합 사례를 회귀 테스트로 재현해 차단했다.
기존 index 미지정 V1 초기 준비는 보존하되 폐기 상태이며 사용하지 않는다.

거래소 달력은2026-10-30~12-31,43개 세션. 휴장/조기마감/DST를 반영했다.
정규장/휴장 출처: https://www.nyse.com/trade/hours-calendars 및 https://nasdaqtrader.com/Trader.aspx?id=Calendar .
달력 source JSON은 공식 페이지 조회에서 정리한 사실이며 다운로드한 원문이라고 주장하지 않는다.
처음 관측이10/30세션에 anchored되고11/2종가 진입한다면20세션 후12/1종가 뒤에야 결과가 성숙한다.
거래소 세션을 사용하며 한국 서버 날짜만으로 horizon을 정하지 않는다.

`quant_forward_validation.py`는 create-only init/freeze/evaluate를 제공한다.
프로토콜 시작 전 기록이나 진입 종가 이후 뒤늦은 cohort동결은 전방 표본으로 인정하지 않는다.
고정한 모든 종목과 벤치마크21개 종가가 있어야 평가하고, 미성숙/누락 표본을 삭제하지 않는다.
현재 실제 전방 cohort는0개. 미래 성적이나 가짜 LIVE 샘플을 만들지 않았다.

실제 DB 준비 조회에서 최신 저장 일봉은10/28, 최신 V9기준일은10/29였다.
이 오래된 예측의 날짜를 다시 붙여 새 전방 샘플로 쓰지 않았다. 새로운 가격/새 배치 관측이 필요하다.
이번 작업에서 앱 서버/정기 배치/외부 시세 수집을 재시작하거나 새 자동화 일정을 만들지는 않았다.
프로토콜과 평가 도구가 준비되었다는 사실과 실제 수집·성숙 결과가 있다는 사실은 다르다.
